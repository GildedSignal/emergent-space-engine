# Predictions (written before the decisive runs)

The run being second-authored (0e9c) proved the doll-local bail (`ES_LOCAL_BAIL`) but borrowed its
10⁹ headline: the shipped trigger `self.bodies/4 + 64` never fires a bail at 10⁴+ on the ladder
(checker's arm 3), so the O(universe) walk it deletes does not exist at scale as shipped. The
checker's gold experiment: compose the bail with 604c's local threshold. This run builds
`ES_LOCAL_THRESHOLD` — the same rule with the doll's registered population in place of the
universe's (`population(idx)/4 + 64`) — and flies the composition.

The invariance argument (holds for any threshold, since all three paths — filtered list, walk the
universe, walk the doll — end in the same cheap tests over the same registered population): the
candidate set cannot move, so no digest can. That is the falsifiable core: if any digest moves, the
index or the tests are not the superset the construction claims, and the whole direction dies.

Arms: `off` (pristine path), `LT` (local threshold, universe walk on bail), `LT+BAIL` (the
composition: both threshold outcomes doll-local).

- **P1 (exactness).** The frozen 13-case × 4-schedule `ladder_digest` record is bit-identical in
  all three arms; the off-arm equals the shipped frozen record `artifacts/runs/nladder/
  ladder_digests_newpop.txt` on every shared case (11 shared cases; the run set adds two wave cases
  the record lacks).
- **P2 (the bail fires at scale, in-band).** On 3999's in-band probe at 10⁵ (belt stand-in's own
  window, root doll): the off-arm bails (walks 100,028, pass 99,714 — 3999's numbers); under LT the
  bail still fires (belt-band occupancy is ≥ doll/4 once N ≳ 700 — the occupancy argument is
  doll-relative, so locality does not save it); under LT+BAIL the walk is the doll's population
  (99,715) with `pass` identical (99,714). In-band the saving is only the ~314 cross-doll bodies:
  O(doll) = O(walk) there, as the checker said — the composition's claim is not a saving in-band but
  that the bail's cost is bounded by the doll everywhere.
- **P3 (the nonlocal coupling, 604c's pair).** Flying the formation scene (200 fleet ships on the
  player's own circle in the player's doll, a 10⁴ belt in the root doll, `formprobe`): off-arm, the
  player's coast scans mostly bail and walk ~9.5×10³ bodies a scan (604c's 78/84 bailed, 9,549
  binding_at); under LT+BAIL the same scans walk at most the player's doll's population (base 28 +
  200 formation + locals ≲ 600) — a ≥ 15× cut, and the same shape at a 10⁹ belt is the ~10⁶× the
  10⁹ sentence needs. The digest at the canonical cut is identical across arms; encounters/kicks
  identical.
- **P4 (the seam census).** `SCAN_CENSUS=1 ladder_digest belt`, off vs LT+BAIL: the off-arm
  reproduces 0e9c's counters exactly (9,280 captures, 2,920 bails, fb_walk 5,374,600, doll_discard
  4,336,560, filt_cand+fb_cand = 2,173,720); the LT+BAIL arm keeps the candidate total identical,
  doll_discard 0, and walked bodies strictly lower (bails answer from the doll; more captures may
  bail under the smaller threshold — that is allowed, only the candidate set is invariant).
- **P5 (the answer half untouched).** On the in-band probe at 10⁵ the answer's candidate count,
  encounter count and slack metrics are identical across arms (the composition touches only who is
  read, never what is computed).

Kill criteria: any digest moves in any arm (P1, P3); a candidate total moves (P2, P4);
doll_discard > 0 on a composed arm (P4); the bail stops firing in-band under LT (P2 — then the
local threshold kills the belt-band bail instead of bounding it, and the composition's claim on
that regime is void).
