**What the author missed.**

"Clusters whenever the wobble rate *exceeds* the drift rate" is χ > 1, which is 67.0%. Still a majority, and the kill does not rest on it (CF ties random in every χ stratum), but the claim sentence attaches the number to the wrong threshold.
- **Crossed indices in the envelope-disjointness formula** (`a[i]*e[j] + a[j]*e[i]`, line 43 of census.py). Immaterial at belt width (Δ ≤ 0.1·a, Δe ≤ 0.05 → 0.2935 vs 0.2934) but a latent bug if reused on wider belts.
