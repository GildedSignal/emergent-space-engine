**What the author missed.**
- The "25–50× a fleet slice" range overstates: within-run ratios are 17.9× (unpaced), 25.5× (paced), 29.6× (rtf 1000); the 50× end only appears by pairing a paced player against an unpaced fleet.
- The quantized key count is not scale-invariant: 51 keys at 48 members, 126 at 200 (96.1% hit). The deletion *fraction* is the robust number; "51 keys" is scene-specific and will grow with the fleet — worth a line in any adoption note.
- The gold experiment's instrument already existed inside this run (the kick bench); stopping at "the profiler measures an unused path" left the attribution gap unclosed when one more wiring step would have closed it.
- The dossier's Commands block does not reproduce the profile JSON (feature flag missing from the build line); a cold checker following only that block hits a compile error.
- Minor: evidence 3 says "1158 kicks" while the memo counts 1125 rebinds (33 samples did not rebind); the two counts are both correct but the prose conflates samples and rebinds.
