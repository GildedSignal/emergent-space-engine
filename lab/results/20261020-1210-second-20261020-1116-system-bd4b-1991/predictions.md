# Predictions (written before the decisive run)

Question (the checker's named gold experiment for 20261020-1116-system-bd4b): per-class
SPAN coverage of the minted arc — the phase walked between a mint and the next rebind of
the same body, divided by the compiled span — on the made, member-cycle and member-passage
classes, folded with the tail-is-cycle correction. It decides whether a class-split/lazy
compile rule prices a real deletion on the kick-cost and memory rows that the composed
Carlson case (closed-form-kernel page: cycles only) and 0757's bounded cache (memory side,
flown) do not already own.

Instrument: the same print-only census on `xtask universe --kick-bench`, extended to hold a
clone of each minted `Binding` and close the row at the body's next fired kick (or the
window end, censored): walked ψ from `Binding::orbit_state` (the shipped readout), never-read
panels counted exactly from the knots' own `psi` values, passages capped at the release
radius `outer_radius/2` (step.rs compiles tubes out to 2× the doll edge and hands the ship
back at the edge, 4:1 hysteresis). No engine code touched; the replay and plane digests must
stay bit-identical to the shipped arm on the same seeds.

Predictions, held out (not tuned on):

- **P1 (cycles walk it all):** both cycle classes (the plane's own bodies and the members'
  cycles) rebind after ≥ ~1 radial period — median span coverage ≥ 0.9, median never-read
  panel share ≤ 10%. Basis: the belt's one-kick-per-period cadence (kick-cadence page);
  4ea0's birth-read census shows every generation read, and a closed orbit re-reads its whole
  table once per period.
- **P2 (the passage tail is real):** member passages rebind or release well inside their
  compiled arc — median never-read panel share ≥ 30%. Basis: the mint's 12.5 KB/kick
  (bd4b), the release cap at half the compiled radius span, and the fleet handing members
  out on short arcs.
- **P3 (the release overhang is unconditional):** for member passages in child dolls, the
  release radius sits at ≤ ~80% of the compiled ψ span, so ≥ 20% of panels are never
  walkable at any kick cadence. If the members' passages all live in the root doll (no
  edge), this prediction is untestable as stated and the run reports the doll census with
  the root-doll walk behaviour instead.
- **P4 (the knot tail is cycle-class and fully read):** the top-knot mints (the 448/257/
  196-knot rows) are cycles whose coverage ≈ 1 — never-read ≈ 0 — so laziness saves nothing
  on the tail and the Carlson/thinned-grid case (which cuts panels at compile time) owns it.
  Basis: the checker's per-row probe (seed 1: body 74, 448 knots, a Cycle).

Kill criterion for the unification's practical content: P1 and P2 both land at never-read
≈ 0 (everyone walks the whole compiled arc) — then a class-split/lazy compile rule prices no
deletion on either row, the memory side is already flown (0757), the cycle CPU side is
already owned (Carlson/thinned grid), and the unification stands as a true but unactionable
double-count warning.

Controls: the replay and plane digests bit-identical to the shipped arm on the same seeds
(the census is print-only and outside the timed section); `refused == 0`; the original
census fields regenerate unchanged (same digests, mint counts, kinds, knot stats).
