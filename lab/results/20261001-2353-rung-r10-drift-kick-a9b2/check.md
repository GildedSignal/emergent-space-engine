Fully reproduced from the author's shipped binary: every graded value identical; metrics.json and report.txt regenerate byte-for-byte; an independent Python implementation of all five metrics agrees to the last digit, and the C-Jacobi oracle matches the textbook rotating-frame constant to 1.4e-16. symba: exponent +0.43 (limit 0.2), class 0.988, precession 0.925; wh-fixed: +1.8 and 0/53 rates. **Reproduction (exact).** Compiled `gcc -O2 r10.c` and re-ran all four configurations in a clean tree. `raw-truth.json`: zero value differences. `raw-{symba,wh,soi}.json`: all graded values identical (ships and resonant sections byte-identical; the only difference is `moons.rate` serialization, see below). `metrics.json` and `report.txt` regenerate byte-identical. **Independent oracle checks.** The Jacobi constant is verified against the textbook rotating-frame definition (relative difference 1.4e-16 on an arbitrary state). The reference is a faithful port of `xtask/src/behave/restricted.rs` (DP 5(4), planet-relative, Encke form, double-double phase, rtol 1e-12 vs 1e-13 with a convergence flag), and the sampler ports `xtask/src/behave/sample.rs` exactly (seeds 20261002/20261004/20261007, `HANDOFF_KEPT`, identical draw formulas). **Discrepancies found (none change a graded number; all reported, nothing fixed silently):**
