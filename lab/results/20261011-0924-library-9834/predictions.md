# Predictions — run 20261011-0924-library-9834 (library lens)

Bottleneck: candidate work at scale (board's top scaling risk, 5 October; HANDOFF risk 1).
Open piece (r8 v2 "next"): steady-state work per orbit → 0, next close conjunction as a
Diophantine problem, certificates that pay once while envelopes are disjoint.

Probe: `probe.py`. Frozen-element coplanar Keplerian pairs (no third-body kicks — the
idealization the certificate must hold in before kicks are added). Per synodic interval k,
strobe phase θ_k = θ_0 + 2παk mod 2π with α = n1/(n1−n2) is exact (mean motions are
linear), so the per-interval minimum distance is D_min(θ_k): the encounter indicator is a
rotation-hitting sequence. Certificate per pair: window width w (largest arc of
{θ : D_min(θ) < R_th}), and a next-hit horizon k̂ = smallest CF-denominator coverage q of
the orbit with max gap < w (three-gap mechanism; guarantees a hit within q intervals).
No encounter is possible before k̂; recheck once there; recompute only on element change.

Sample: 300 random pairs, a ∈ [0.97, 1.03], e ≤ 0.08, random ϖ, M0, Δa ≤ 0.03;
K = 1024 intervals, 32 samples/interval; R_th = 0.005·a (belt-like encounter tier) and
0.002·a for sensitivity. Controls: exact 2:1 resonant pair (phase frozen: all-or-nothing),
disjoint-radial pair (w = 0 exactly, zero hits), near-circular |Δa| < R_th pair (w = 1,
hit every interval).

Written before the run. Kill criteria in brackets.

- **P1 (the generator).** Fit the hit-window W on even-index intervals, predict hits on
  odd-index intervals from (α, θ_0, W) alone. Mismatch rate < 1% of intervals outside a
  boundary band |D_min − R_th| < 5% R_th. [Kill the representation if mismatches exceed
  1% outside the band: then the pair's future is not generated by the rotation number and
  storing (α, W) buys nothing.]
- **P2 (deletion).** Of pairs whose radial ranges overlap, ≥ 30% have w = 0 at
  R_th = 0.005a: deleted from the candidate tier until elements change. [If < 5%, this
  configuration buys nothing at this threshold; report, method alive.]
- **P3 (zero-miss horizon).** Across all rolling predictions (after each hit, from the new
  phase), zero cases of the true next hit occurring at or after the predicted horizon
  (safety), and median efficiency (true gap)/(predicted horizon) ≥ 1/4 (not wastefully
  early). [Any safety violation kills the certificate for this configuration. Median
  efficiency < 1/20 kills it as not worth building.]
- **P4 (the tail rules).** The gap distribution across pairs is fat-tailed: p99/median
  ≥ 10. A single belt-wide safe cadence must use the worst pair's minimum gap, so its
  work per pair is ≥ 10× the certificate's on the median pair. [If gaps are near-uniform
  (p99/median < 3), a fixed cadence is fine and the per-pair CF machinery is not needed.]

Expected gain if all hold: candidate-tier steady-state work per pair per orbit drops from
O(1) (per-orbit recheck) to O(w) rechecks per interval amortized to one CF computation per
element change — the "each pair paid once per element change" target.
