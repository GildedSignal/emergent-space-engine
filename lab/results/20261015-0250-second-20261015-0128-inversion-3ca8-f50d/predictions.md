## Pre-registered expectations (not tuned on)

1. **Control-pos (equal masses, β 0.05):** engine ≈ exact — contacts within ~5%,
   final γ quantiles equal to ~4 decimals. If contacts differ > 10%, my twin is the wrong
   instrument and the run reports that, not the law.
2. **neg (two-body pump, the checker's unattributed residual):** the first run's float
   twin ended at γ 186.6 vs engine 150.8 (1.24×) with contacts −8%. I expect the exact
   twin to close most of the gap: final γ within 1.15×, contacts within ~8%, dwell totals
   within ~5%. Both arms stay in one class (pumped to the ceiling, dwell ~1.0×10⁶).
3. **pump (decisive, seeds 1–4):** engine ≈ exact on every class metric: trapped within
   ±20% of 64; dwell-γ2 totals within ~10%; **max continuous dwell within 1.5×** (the
   first run's float twin was 4.8–6.2× off — this is the metric that dies); contacts
   within ~5%; final γ p50 within ~15%. If instead ANY class metric deviates ≥ 2× in the
   same direction on ≥ 3 of 4 seeds, the false-class claim stands with a valid instrument.
4. **Q-flat:** engine at Q = 2¹⁶ and 2¹⁸ vs the exact twin agrees as well as Q = 2²⁰ does
   (the first run's Q-flat finding was measured against the wrong twin; against the right
   one it should still be flat).
5. **New scenes:** `soft` (100:1, β 0.8 — lower contrast, faster) and `tall` (128 lights,
   512×8 — double density scale): engine ≈ exact within the same bands as pump. The
   pass-through fraction is a rule property: I expect it high (≥ 0.5) in every scene and
   highest in `soft` (faster closing speeds cross the bin more often), ~0.87–0.88 in pump
   as the checker measured.
6. **Ledgers:** engine residuals stay finite (no blow-up) in every engine arm.

Kill criterion for the inversion claim: if the exact twin fails the pos control (item 1),
or if its per-contact agreement with the engine is only head-on (micro table above says it
is not), the ensemble comparison is void and the run reports the instrument defect.
