# Run 20261015-0358-redteam-8144 — premise red-team: the contact law at speed

**Claim.** `docs/representation.md` §2's "Contacts use the exact integer special-relativity
law" is false for every pair whose closest approach falls inside its detection chronon: on
the shipped lattice the contact is detected and logged but the receding-skip gate drops the
impulse, so **any ship-scale pair closing faster than its own combined radius per 4.925 µs
ghosts through** — a 0.5 m missile at 0.9c never collides with anything, and no rung, gate
or engine test can see it.

**Bottleneck.** Not a cost bottleneck: a correctness hole in the law (the board's lens-0
domain, "the representation"). The measured boundary is exact and closed-form
(skip ⟺ τ\* ≤ 1, i.e. `d0 ≤ |w|`), so the fix deletes nothing but is one rule: resolve at
the crossing the detection quadratic already finds. What it deletes if left alone is a
behaviour class the game exists for (collision play at high c).

  (chaos-shadowing, f50d) — lattice-scale bodies are ρ ≪ 1, so the decomposition predicts

## What would make it wrong, adoption cost, principles

- **Wrong if** the skip is the intended semantics for fast contacts (a design choice, not
  an oversight). Then `representation.md` §2's sentence is wrong instead, and the
  player-visible consequence (ramming at high c does nothing) stands either way — one of
  the two must give.
- **Adoption cost:** one rule in `respond`/`resolve_law` — resolve at the crossing time the
  detection quadratic already computes exactly (τ\* = −d·w/|w|², rational; the v1 reflection
  needs no root), with the double-resolution guard re-scoped to consumed pairs. A canon
  reset (bits change); r5 re-frozen with the criterion above. No new state, no new cost per
  contact.
- **Principles.** This is an error of *type*, not size (principle 2: "error type over error
  size"): a whole interaction class is absent, and it cannot compound — it is simply
  missing. Principle 30: "what really matters is navigation, knowledge and dynamics those
  need to be perfect" — dynamics at the contact interface is wrong precisely in the
  regime the goal names ("it lets the player feel what living at high c would feel like").
  §2's own sentence is the premise killed.
