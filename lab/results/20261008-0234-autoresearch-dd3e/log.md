# log.md — autoresearch loop (artifact: the plane's kick path, crates/universe + crates/space; metric: µs per pure kick resolve, behaviour gate: whole-universe digest at the canonical cut 3e10 ticks)

Machine: shared Linux runner (8 vCPU), load 2–7 during the run (four foreign python jobs part of the time); the digest is load-independent. Every kept change was gated on the tuning config's digest (seed 1, members 8, sparse) before the next round. A/B against the saved base binary back-to-back to cancel drift.

- **baseline**: pure kick 33.7 µs (uncontended) / 57 µs (under foreign load). Phase split: rebind 22.2 (compile 11.6 + decode/bookkeeping 10.6), readout 3.3, secondaries 3.4, tide 3.4, force 0.9. Whole universe: 50.1 µs/item, ships 32.0. Digests of four configs recorded (baseline.txt).
- **R1 (kept)** — hypothesis: `rebind` decodes the old tube's orbit state at `event_time` every kick, but that value is a constant of the immutable binding. Change: cache it (`Binding.tau_event`, filled at every construction from the same `decode` call; `None` falls back to the old path, so error behaviour is unchanged). First attempt gained ~0.3 µs because ships' bindings are rebuilt by `set_mass` → `bind_exact`, which had left the cache empty; filling it there too completed the round. Metric: tau0-lookup 3.35 → 0.02 µs; total kick −1–4 % (within load noise on the total, but one full decode per kick removed). Digest identical. **kept**.
- **R2 (kept)** — hypothesis: `rebind` decodes the old tube at the kick tick `t`, but `kick()` (and `kick_clock`, and the burn flush in `decide`) has just decoded the same binding at the same tick in `readout`. Change: `readout_with` returns the orbit state with the integer state; the proper time at `t` is passed into `rebind` (callers without a fresh read pass `None` and take the old path). Metric: 33.2 → 27.0 µs interleaved A/B (−18 %); `orbit_state(t)` phase fell to 0.00 µs. Digest identical. **kept**.
- **R3 (not run — stopped on the run's 60-minute budget)** — next round named: `compile(from_state)` is now 43 % of the kick (11.5 µs; `fit_key` + `Orbit::compile`'s quadrature; the crate's `profile` feature only instruments the `Cycle` compile, not `Orbit::compile`), and the three remaining decodes (own readout 3.4, secondaries 3.4, tide 3.3) invite a cross-body same-tick memo in `Ctx` (pure function of (binding, tick)), which the single-ship bench cannot even see — it pays at fleet scale.

Stop condition: not met (no three consecutive sub-10 % rounds); the loop stopped on time.
