   an encounter across a doll edge), the per-doll proxy is unsound: the tell is
   `Refused("history pruned")` (ctx.rs:62, observe.rs, ext.rs) or any `ladder_digest` bit move;
   the scope then widens to the item's light diameter — still per-reader, still bounded, but
   dearer. This is the named falsifier the next (flight) run owns.
2. **The constants** (2 KB/binding, 27.6k gs period) are 3×10⁴–10⁵-scale measurements; if the
   per-binding byte cost grows with N, the ruin rows scale with it (the ordering does not move).
3. If held scans ever read *through* history rather than holding their own copies
   (encounter.rs:42 says they hold), `oldest`'s read set widens beyond ship items.
