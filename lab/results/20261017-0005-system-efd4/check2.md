## What the author missed

- **The dossier overstates the creation-CPU deletion**: "deletes … the creation compile for program-minted bodies on shared orbits (16.4 µs × duplicates)". Measured with the intern on, creation is still ~16 µs/ship — the compile runs before `insert`. Deleting it needs the mint to consult the key before fitting, which is not flown (the page corrects this; the dossier does not).
- **The census key omits the passage edge** (`crates/space` interns passages by `Option<Scalar>` edge; the test's key does not). No effect on these streams (0 aliased groups), but it could overstate duplication on passage-heavy streams; the intern key must carry it, as the page now says.
- **Concentration + kicks is untested**: the formation dies at 0 kicks and the kicked belt is unconcentrated, so duplication on a concentrated *and* kicked stream is unmeasured. The intern is key-based so the argument carries, but a surviving kicked formation would close it.
- **Release-on-death (the corpse term) is unflown**: with the intern the corpse *cost* collapses (512 entries → 1) but the corpses still stand (the belt's +8).
- **Per-orbit scoping**: 99.6% is at one (radius, e); a formation spread over N distinct orbits stands at N keys — the gain per formation is (ships/key), worth stating in the adopting step's estimate.

## Reproducing the intern flight

My instruments stay in the tree (`cache_duty_check2.rs`, `cache_duty_intern.rs` — both run on shipped code and print; the check2 asserts describe the shipped mint). To fly the intern, apply to `crates/universe/src/bind.rs`: import `OrbitKey` and `HashMap`; give `Catalogue` two fields `ids: HashMap<(Scalar, bool, OrbitKey, Option<Scalar>), u32>` and `refs: Vec<u32>`; in `insert`, compute `intern_key(e) = e.trajectory.key().map(|k| (e.unit.mu, e.clockwise, k, match &e.trajectory { Trajectory::Passage(p) => Some(p.outer_radius), _ => None }))` — on a hit bump `refs` and return the id, on a miss mint a slot (refs=1) and record the key; in `release`, decrement `refs`, and only when it reaches 0 take the slot, push to `free`, and drop the key from `ids`. Then `cargo test --release -p emergent-universe --test cache_duty_intern -- --nocapture --test-threads=1`: formation 513→2 standing (before and after death), all four digests identical to the shipped build.
